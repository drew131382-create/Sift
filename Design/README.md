# Sift 界面设计

## 当前方向
以白色留白、黑色文字和高饱和亮黄表达简洁的信息工具。轻拟物只体现在纸卡的细边、接触阴影和少量堆叠层次中。

参考 [Airbnb 官方新版应用展示](https://news.airbnb.com/product-releases/airbnb-2025-summer-release) 的搜索入口和内容分组。将清晰层级、减少重复信息、突出主要操作应用到 Sift；配色和组件仍按 Sift 的需求实现。

## 配色与组件
- 强调色：亮黄 #FFD600，浅色与深色模式保持同一种黄色。
- 黄色上的文字：#171717，实测对比度 12.70:1。
- 浅色：背景与纸卡 #FFFFFF、正文 #222222、辅助文字 #686868。
- 深色：背景 #161616、纸卡 #222222、正文 #F5F5F5、辅助文字 #B6B6B6。
- 主文字对比度：浅色 15.91:1、深色 16.60:1；辅助文字：浅色 5.57:1、深色纸卡 7.85:1。
- 卡片圆角 20pt。低强度纸面渐变、半点细边和轻阴影保留触感。
- 主要按钮与选中日期采用亮黄和黑字；黄色不用来承载小字号白字。
- 使用系统字体、动态字号与减少动态效果设置。

## 精简内容
- 首页顶部仅保留页标题、扫描和导入入口，移除大标语、日期、说明。
- 搜索与筛选合并为一个控件。重复的四个分类快捷按钮移除，分类筛选在右侧筛选入口中继续可用。
- 四组堆叠保留固定顺序。分类使用亮黄色标签，明确显示实际卡片数量与展开操作；折叠后错位露出最多两张背板，展开后纸卡轻微重叠。
- 卡片采用左侧截图、右侧标题和字段的统一布局；数字使用较小的标题字号，取件码以亮黄色小标签突出。最多两条去重背景信息，完整字段保留在详情。
- 移除卡片中的重复类别、创建日期、普通待处理状态和缩略图浮动放大按钮。待确认、已完成、已归档状态继续明确显示。
- 图片按钮与文字详情入口仍独立；点图直接打开本地原图。
- 空状态采用单个小图标，不叠加四组空卡。\n- 底栏包含今天、待确认、信息库、设置。设置提供真实照片权限、内置模型信息、存储统计与缓存清理、隐私说明。首页重复的隐私入口移到设置中。
- 详情页去掉大面积黄色背景；次要设置改为分隔线式折叠项。
- 扫描页去掉宣传标题、装饰图标和重复说明，保留日期、数量、权限与错误提示。

## 真实数据与交付
应用启动直接使用本地数据仓库。示例卡片、生成的示意截图和 --ui-fixtures 注入入口已移除；旧示例预览也已移除。没有真实信息时显示空状态，打开设置不扫描相册、不启动模型推理。

previews 仅保存当前模拟器真实本地库的界面截图：home-light.png、home-dark.png、settings-light.png、settings-large-text.png。当前库为空，首页如实显示空状态；真实截图导入后才显示内容卡片。原有依赖 --ui-fixtures 的 UI 测试需改为独立测试数据注入流程，本轮未运行自动化测试。

开发用 DEBUG 路由仅切换页面，不创建数据：
- --preview-settings / --preview-review / --preview-library：对应标签页。
- --preview-detail：有真实卡片时进入首张卡片详情。
- --preview-category purchases / schedules / collections：分类筛选。

设置中的空间统计只读取文件元数据。模型状态检查内置清单、文件存在性与大小；推理时仍由原有加载器执行完整校验。清理操作释放缩略图缓存并移除未被卡片或任务引用的临时图片，识别运行时暂停提供清理操作。

本轮构建记录：
- 模拟器：/tmp/Sift-settings-stack-simulator.log。
- iPhone：/tmp/Sift-settings-stack-device.log。
